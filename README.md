# 📰 Bangla News 24

A modern and responsive Bengali news website built with **Next.js**. Stay updated with the latest news across different categories through a clean and user-friendly interface.

## 🌟 Features

* **Latest News:** Browse the latest Bengali news from different categories.
* **Category-Based News:** Explore news by category for easy navigation.
* **News Details:** Read complete news articles with detailed information.
* **Responsive Design:** Optimized for mobile, tablet, and desktop devices.
* **Dynamic Data Fetching:** Fetch news articles and sections from a news API.
* **Loading UI:** Smooth loading experience while fetching news data.
* **Custom Error Pages:** User-friendly pages for unavailable or invalid routes.
* **Authentication:** User authentication with Better Auth.
* **Modern UI:** Clean layout with a focus on readability and accessibility.

## 🛠️ Technologies Used

* **Next.js** – React framework for building web applications
* **React** – Component-based user interface
* **TypeScript** – Type-safe development
* **Tailwind CSS** – Utility-first styling
* **DaisyUI** – UI components and styling utilities
* **Better Auth** – Authentication and session management
* **MongoDB** – Database integration for authentication
* **News API** – Fetching news articles and categories
* **Vercel** – Deployment and hosting

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/abirjuboraj/bangla-news-24
```

**2. Navigate to the project directory**

```bash
cd bangla-news-24
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env.local` file in the root directory and add the required environment variables for authentication and database connectivity.

```env
MONGODB_URL=your_mongodb_connection_string
BETTER_AUTH_URL=http://localhost:3000
BETTER_AUTH_SECRET=your_auth_secret
```

Replace the placeholder values with your actual configuration. Check your project's authentication setup for any additional required variables.

**5. Run the development server**

```bash
npm run dev
```

Open http://localhost:3000 in your browser to view the application.
